# 功能范围

## 支持的功能

TwinCoach 面向单人深蹲训练，支持双摄采集、双路完整 33 点姿态、动作阶段判断、计次、规则评分、数字人跟随及 HDMI 反馈。计算在 KV260 上执行，PC 负责 SSH 控制。

深蹲评分由正面与侧面观测共同提供，结果包含规范度、观测置信度和可解释建议。双路姿态 为默认模式，混合推理模式通过显式配置启用。

## 运行依赖

完整运行需要匹配的模型、DPU IP、固件、内核驱动、ARM 原生库、角色和实际相机参数。准备方法见 [资产说明](assets.md) 与 [构建说明](../build/readme.md)。

## 使用边界

- 演示与测试以单人深蹲为主，其他动作需要独立协议和验证数据。
- 规则分数表示动作与配置规则的符合程度，不等同于模型识别准确率或医学评估。
- 遮挡、人物超出有效视野和低置信度会影响观测有效性。
- 标定与角色绑定需要匹配实际相机和人物资产，通用示例不能替代标定。
- 视频输入、姿态更新和显示完成分别计量，性能数据的输入及统计方法见 [性能说明](results.md)。

扩展方向见 [项目路线](roadmap.md)。
