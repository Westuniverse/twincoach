# 性能与资源

本页给出 TwinCoach 双 Full33 链路的测量条件、吞吐、源龄及 FPGA 实现资源。机器可读数据见 [data/results.json](../data/results.json)。

## 回放性能

输入为 2698 张录制 JPEG，总时长 45.019937339 秒。统计窗口为输入开始后的 15–44 秒，以 GPU/HDMI 完成确认的新姿态对计数。

| 指标 | 结果 |
| --- | ---: |
| 新姿态对确认 | 668 |
| 新姿态对更新率 | 23.034483 次/s |
| 最低滚动一秒更新数 | 20 |
| P95 源龄 | 290.432884 ms |
| 最大确认间隔 | 104.667745 ms |

摄像头短运行的有效输入各约 29.9 FPS。输入采集率、姿态更新率和物理屏幕延迟是不同指标；上述回放结果不代表持续真人识别帧率。源龄以输入时间戳到 GPU 完成确认为边界。

DPU AXI/core 100 MHz，DPU 2x 与 Tail4 200 MHz，ROI/DMA/shared 100 MHz；DDR 交换与 HP0 出口 200 MHz。实现报告位于 build/di46/reports。

## DDR 互连比较

相同输入条件下，DDR 交换/出口 100 MHz 的更新率为 23.551724 次/s，200 MHz 为 23.310345 次/s。提高互连时钟没有形成端到端吞吐收益，ARM 和显示流水仍影响系统表现。详见 [DDR 分析](ddr.md)。

## 验证范围

工程创建与 BD 校验、主机功能测试、RTL 自检、综合实现和板端测量分别提供证据。整板功耗、持续真人姿态更新率与独立动作标注准确率尚无对应评估数据。
