# 项目路线

TwinCoach 围绕双视角运动指导扩展功能，同时保持本地处理、可解释评分和板端运行的设计原则。

## 运动指导

- 扩展动作协议，明确每种动作的有效观测、阶段状态和计次规则。
- 建立独立标注数据集，评估计次、姿态质量与反馈建议。
- 支持使用者体型与相机布局的标定配置。

## 数字人

- 改善头部、掌向和遮挡情况下的姿态表现。
- 支持不同角色骨骼与材质，保留可追溯的观测和推断标记。
- 优化低置信度与重新捕获时的显示连续性。

## 系统性能

- 优化 ARM 解码、几何准备与 GPU 提交流水。
- 根据完整链路吞吐、源龄和资源占用选择硬件加速路径。
- 完善长时运行、资源回收与断流恢复测试。
