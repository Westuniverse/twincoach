# 动作协议

## 输入与视角

系统面向单人深蹲。侧面提供深度、躯干和矢状面指标，正面提供左右对称和额状面指标。原始姿态与观测置信度用于评分，显示稳定与数字人修正单独处理。

[规则文件](../data/examples/squat.json) 是可执行配置来源，经 [源码映射](../build/sources.json) 装配为 config/exercises/squat_process_v1.json。阈值和权重是工程规则；规范度分数表示规则符合程度，不等同于姿态模型准确率。

## 阶段与计次

[状态机](../src/host/posepriv_coach/exercises/squat_tracker.py) 根据膝角与时间戳组织站立、下降、底部和上升阶段，进入和退出使用不同阈值。

| 配置项 | 示例值 | 用途 |
| --- | ---: | --- |
| standing_min | 160° | 站立阈值 |
| descending_enter | 150° | 下降进入阈值 |
| bottom_max | 110° | 底部阈值 |
| ascending_enter | 120° | 上升进入阈值 |
| maximum_tracking_gap_ms | 1000 ms | 中断后使未完成动作失效 |

完整动作才形成一次计数。默认 missing_tracking_policy=reset；可选 hold 只在同一时间上限内保留内部阶段，缺失观测不推进计次，也不刷新最后有效时间。对外的当前阶段与内部保留阶段须区分。

## 全过程评分

| 指标 | 观测 | 示例理想区间 | 权重 |
| --- | --- | --- | ---: |
| 下蹲深度 | side_depth_ratio | 0.9–1.1 | 0.30 |
| 躯干角度 | side_trunk_angle_deg | 10–35° | 0.25 |
| 膝部对称 | front_knee_symmetry | 0.9–1.1 | 0.25 |
| 动作节奏 | tempo_seconds | 2–4 s | 0.20 |

过程评分处理有效覆盖、底部窗口、时间间隔与持续偏差；配置同时保存容差、最低时间覆盖和观测置信度。最深帧评分与全过程评分属于不同量表。算法入口见 [session.py](../src/host/posepriv_coach/session.py)。

## 反馈与恢复

一次动作完成后形成“下次建议”，保留到下一次动作完成。短时丢失观测不会覆盖已有建议；无效完成结果显示观测不足，不沿用旧分数。应用重启重置计次和建议。

超出追踪间隔的半次动作丢弃，恢复时不能跨中断拼接计数。实现与确定性检查见 [CompactCoach](../src/host/posepriv_coach/compact_coach.py) 和 [主机测试](../sim/test_coach.py)。这些测试覆盖反馈行为；独立标注的真人计次与规范度准确率仍需要另行评估。

## 扩展动作

新增动作应给出观测视角、必需关键点、有效条件、阶段阈值、完整计数规则、单位、权重和确定性序列。相机布局及使用者差异需要对应标定和数据评估，不能直接把深蹲规则复制为其他动作的准确率结论。
